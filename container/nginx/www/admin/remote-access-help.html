Connect your player website

Cloudflare and Tailscale are built into PhValheim. Open admin and choose Remote Access. You do not need another container, extra mounts, Docker permissions, or a separate client installation.

Cloudflare: public website

  1. In your Cloudflare account, create a tunnel and copy its connector token. Do not run the install command: PhValheim runs the connector.
  2. Add a published application hostname on your domain. Select HTTP and use http://127.0.0.1:18080 as the origin. This is PhValheim's built-in player-website gateway; do not publish that port or route to admin.
  3. Choose Cloudflare in Remote Access, paste the token and your full HTTPS website URL, then select Connect and test. Follow the live checks for DNS, TLS, routing, and connection problems.

Tailscale: private website

  1. Choose Tailscale, select Sign in to Tailscale, and open the generated sign-in link. Approve the device in your account if asked.
  2. Enable MagicDNS and HTTPS in Tailscale DNS settings. Permit your intended devices to reach this device on HTTPS port 443.
  3. Select Connect and test, then open the test link on another authorized Tailscale device. Players need Tailscale; this option does not make your website public.

Open admin securely

Enter credentials over a directly secured HTTPS admin connection or on http://localhost:8081. If you need secure access from another computer, you can forward the admin port:

ssh -L 8081:127.0.0.1:8081 USER@YOUR_SERVER

Replace the placeholders with your SSH login and server, leave that connection open, and visit http://localhost:8081. The future public tunnel does not secure a plain HTTP admin session.

Stop or change access

Disconnect stops access and keeps settings. Disconnect and forget also removes local credentials. Delete unused tunnels, hostnames, or devices from the provider account separately. Remote Access configures the player website; Valheim game connections keep their existing settings.
