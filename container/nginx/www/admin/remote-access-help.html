Remote Access

Choose Website for your player portal, or Game connections for a world’s UDP ports and crossplay mode.

Cloudflare and Tailscale are built into PhValheim. Open admin and choose Remote Access. You do not need another container, extra mounts, Docker permissions, or a separate client installation.

Direct connection

Publish container TCP 8080 to a host port. Point your public DNS/DDNS name at your public IP. Configure an HTTPS reverse proxy to that host port, forward TCP 443 to the proxy, and allow it through the host firewall. Keep admin 8081 private. Test from a phone with Wi-Fi off; the local website check cannot verify your router.

Game connections

Select a world to see its assigned UDP pair. For Steam/direct access, publish both UDP ports in Docker, Unraid, or TrueNAS (skip this with host networking), forward the same ports from your router to the server’s reserved LAN IP, and allow both through its host firewall. Use your public Game DNS and first port to test a join from another network. Cloudflare game DNS records must be DNS-only.

Crossplay uses the PlayFab relay and needs no inbound game port forwarding. Join through the code or server list, not a local/loopback IP. Outbound access is still required. The modal labels running versus saved mode and flags pending restarts. Website tunnels do not carry game UDP. Double NAT and CGNAT can prevent direct access; use crossplay or obtain a public IP.

Valheim dedicated server guide

Cloudflare: public website

  1. In your Cloudflare account, create a tunnel and copy its connector token. Do not run the install command: PhValheim runs the connector.
  2. Add a published application hostname on your domain. Select HTTP and use http://127.0.0.1:18080 as the origin. This is PhValheim's built-in player-website gateway; do not publish that port or route to admin.
  3. Choose Cloudflare in Remote Access, paste the token and your full HTTPS website URL, then select Connect and test. Follow the live checks for DNS, TLS, routing, and connection problems.

Tailscale: public website

  1. Choose Tailscale, enter a Website name, select Sign in to Tailscale, and open the generated sign-in link. Approve the server device if asked.
  2. Select Publish website. If prompted, choose Enable public access in Tailscale and complete approval; PhValheim retries automatically.
  3. Share the HTTPS link. Players need no Tailscale app or account. Test the link on a phone with Wi-Fi and Tailscale off, then test a client download.

New public DNS records can take up to 10 minutes. Funnel uses a Tailscale hostname and has provider bandwidth limits. Funnel setup and limits.

Stop or change access

Disconnect stops access and keeps settings. Reconnect restores Tailscale and publishes using the saved device. While disconnected, edit Website name and reconnect to apply it, or choose Save name to leave access off. Changing the name changes the public link; the actual assigned address appears after Tailscale confirms it. Expand Website checks for diagnostics. Disconnect and forget also removes local credentials. Delete unused tunnels, hostnames, or devices from the provider account separately. Remote Access configures the player website; Valheim game connections keep their existing settings.
