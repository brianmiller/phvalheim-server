Install the secure Remote Access connector

This is a one-time installation for the development build. Afterward, Cloudflare and Tailscale setup happens in the Remote Access modal.

Keep your existing PhValheim data volume, environment, and ports. Add a shared socket volume to that existing service. Do not replace its data volume with a new example volume.

Docker Compose

  1. Use theoriginalbrian/phvalheim-server:dev for your existing PhValheim service.
  2. Add remote-link:/run/phvalheim-remote to that service's volumes.
  3. Add the connector service and volumes/network below to your Compose file.
  4. Recreate the services using your normal deployment tool. Open Remote Access in admin; the connector should report Off until you configure it.
services:
  remote-access:
    image: theoriginalbrian/phvalheim-server:dev
    entrypoint: ['/opt/stateless/remote-access/start.sh']
    environment:
      PHV_REMOTE_CONNECTOR: '1'
    volumes:
      - remote-link:/run/phvalheim-remote
      - remote-state:/var/lib/phvalheim-remote
    networks: [remote-egress]
    cap_drop: [ALL]
    cap_add: [NET_ADMIN, SETPCAP, SETUID, SETGID, CHOWN, FOWNER, KILL]
    security_opt: ['no-new-privileges:true']
    read_only: true
    tmpfs: ['/tmp:rw,nosuid,nodev,noexec', '/run:rw,nosuid,nodev,noexec']
    restart: unless-stopped
    pids_limit: 128
volumes:
  remote-link:
  remote-state:
networks:
  remote-egress:
    driver: bridge

Publish no ports on the connector. Never use host networking, share PhValheim's network namespace, or mount the Docker socket. Use a separate socket volume for each PhValheim instance. Keep the connector's private state volume out of ordinary backups/exports.

Linux Docker is the initial supported setup. Unraid/TrueNAS need equivalent separate-container settings; their native installation flows are not yet validated. Do not disable isolation to make an unsupported configuration work.

Open admin securely

On the Docker host, open http://localhost:8081. From another computer, open an SSH tunnel and keep it running:

ssh -L 8081:127.0.0.1:8081 USER@YOUR_SERVER

Use your SSH user and server in place of the placeholders, then open http://localhost:8081 in your browser. Choose another local port if 8081 is occupied. Remote Access accepts credentials on loopback or a directly secured HTTPS admin connection; spoofed forwarding headers do not make HTTP secure.

Connect your account

Return to admin and open Remote Access. The Cloudflare modal walks you through creating a tunnel and hostname route. The Tailscale modal provides a browser sign-in link and instructions for private HTTPS access. Both show real connection tests and next steps when a check fails.

Remote Access connects the player website. It does not expose admin or configure Valheim's game ports.
