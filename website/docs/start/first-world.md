# Create your first world

Start with a small world and a short mod list. You can grow it once everyone can join.

## 1. Choose vanilla or modded

| I want… | Choose |
| --- | --- |
| Stock Valheim, with no client mod setup | **Vanilla world (no mods)** |
| A shared collection of mods | A modded world |
| To try a mod made with Hugin | A separate modded test world |

Create a world from the admin dashboard. Give it a name and review its settings. For vanilla worlds, set a password that meets the rules shown in the UI. [More about vanilla and crossplay →](../host/vanilla.md)

## 2. Pick mods, if you want them

Open the world's **Mods** controls and search the catalogues. You can mix Thunderstore, Hexium and locally published Hugin's Vibes mods.

Keep the first set small. PhValheim resolves dependencies, but individual mods can still conflict with each other or with a new Valheim version.

[Choosing mods, versions and configs →](../host/mods.md)

## 3. Decide who can join

Open the world's **Settings → Access** tab. With **Use Access List** enabled, add the players who should be allowed in. Admins and bans have their own lists.

[Access lists and player IDs →](../host/access.md)

## 4. Let the world finish preparing

Watch the world's status and **Logs** while it downloads or updates. Start it when it's ready. If it fails, the log for that operation is the place to look.

## 5. Send your friends the public website

Players open your public PhValheim website. For a modded world, they install the PhValheim client, sign in with Steam, and use the world's launch link. For vanilla, they use the connection details with ordinary Valheim.

[Share the player guide →](../play/join.md)

!!! tip "Set up a backup before the big adventure"
    Check **Backups** after the first successful start. A dedicated backup volume enables scheduled backups. [Configure backups →](../host/backups.md)
