# Reporting a security vulnerability

Use [GitHub private vulnerability reporting](https://github.com/brianmiller/phvalheim-server/security/advisories/new)
to report a suspected vulnerability to the maintainer. Reporting is enabled for this repository.
For a cross-repository problem, submit one private report and name the affected repositories.

Include affected versions, prerequisites, expected and observed behavior, and a minimal
reproduction using synthetic data. Redact credentials, tokens, player Steam IDs and world
passwords. Do not publish exploit details, private logs or a public fix PR before coordinating
with the maintainer. If the private form is unavailable, ask the maintainer on Discord for a
private reporting route without posting vulnerability details in a public channel.

PhValheim is maintained by volunteers; there is no guaranteed response time. Security fixes
are delivered through current releases. Include your exact version so the maintainer can
assess older versions; do not assume every older release receives a backport.

For ordinary bugs and feature requests, use GitHub issues. Keep the server admin interface
private and follow the server installation guide when configuring access.
